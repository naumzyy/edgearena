# PulseMatch landing

Нейтральный sports-tech лендинг без визуального/текстового брендинга букмекера.

## 1. Перед публикацией

Открой `config.js` и замени:

- `affiliateUrl` — на реальную партнёрную ссылку оффера;
- `operatorName` — на юридическое лицо лицензированного оператора;
- `licenseInfo` — на номер лицензии и орган, который её выдал;
- `yandexMetrikaId` — ID Яндекс Метрики или `null`.

Открой `privacy.html` и замени `[ДОМЕН]`, данные владельца страницы и email.

## 2. Что уже умеет

- полностью адаптивный лендинг;
- CTA на партнёрную ссылку;
- сохранение `utm_*` и `yclid` при переходе;
- optional Яндекс Метрика + цель `offer_click`;
- мобильная sticky CTA;
- блок 18+ и предупреждение об игровой зависимости;
- юридический блок под лицензию;
- никакого брендинга/цветовой системы ФонБет.

## 3. Render (бесплатный Static Site)

Самый простой способ:

1. Создай новый GitHub/GitLab репозиторий и загрузи содержимое этой папки в корень.
2. В Render: **New → Static Site**.
3. Подключи репозиторий.
4. Build command можно оставить пустым или `echo "static"`.
5. Publish directory: `.`
6. Нажми Create Static Site.

Render выдаст адрес вида `https://<name>.onrender.com`.

`render.yaml` также лежит в проекте, если захочешь использовать Blueprint.

## 4. Важно для РСЯ / букмекеров

Этот шаблон не подменяет юридическую проверку. Перед трафиком убедись, что данные лицензии и рекламные материалы соответствуют требованиям страны показа и условиям партнёрского оффера.
