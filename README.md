# Пульс Спорта — лендинг спортивной платформы

## Что изменить перед запуском

Откройте `config.js` и заполните:

1. `offerUrl` — реальная партнёрская ссылка.
2. `yandexMetrikaId` — ID Метрики или оставьте `null`.
3. `operatorName` — юридическое лицо лицензированного оператора.
4. `licenseText` — номер лицензии и орган, выдавший её.
5. Тексты бонусов — только в соответствии с фактическими условиями оффера.
6. `liveProof` — только реальные подтверждённые выплаты. Если массив оставить пустым, блок автоматически скрывается.

## Render

### Вариант 1: Blueprint
1. Создайте GitHub-репозиторий.
2. Загрузите в него содержимое этой папки.
3. Render → New → Blueprint.
4. Подключите репозиторий.
5. Render прочитает `render.yaml` и создаст Static Site.

### Вариант 2: Static Site вручную
- Build Command: оставить пустым.
- Publish Directory: `.`

## Метрика

Если в `config.js` указан `yandexMetrikaId`, счётчик подключится автоматически.
Цели:
- `offer_click` — клик на CTA;
- `bonus_select` — выбор бонуса.

## Важно

Перед рекламным запуском проверьте текст бонусов, сроки выплат, реквизиты лицензии и предупреждения на соответствие фактическим условиям оффера и требованиям рекламной площадки.
